**A:** Replicate C git's documented `git bugreport` command-line contract. The issue asks for support of the git bugreport command itself and names "standardized bug reports", so existing tooling and habits around `git bugreport` should carry over: the default output file name and format, `--output-directory`, and `--suffix` should match what git documents, and the report should collect the same kinds of information git's does (system/environment information and repository information) as far as this project can provide them. `--diagnose` (the compressed diagnostics archive) is optional for this feature: include it only if it fits naturally; otherwise leave it out and state that in the documentation.
